# 会议废话率评估智能体

一个单文件、离线可用的会议效率复盘工具：接入会议纪要，逐句判断发言是否与议题相关，统计「废话率」，并找出废话最多、最长、最离谱的人。界面默认卡通潮酷风格，可一键切回商务经典风格。

## 功能

- **会议纪要接入**：粘贴或上传 TXT / MD / CSV / JSON，自动识别 `张三 09:30：…`、`【张三】…`、`张三（10:32）：…`、`[10:35] 张三: …` 等格式。
- **废话判定**：按议题关键词重合度、口头禅、重复度、信息密度、闲聊词综合打分，阈值可调；可选接入兼容 OpenAI 的接口做 AI 语义复核（密钥只留在当前页面内存）。
- **八页分析**：废话排行榜、时间轴密度曲线、逐句明细、废话类型、批注版纪要、多场会议对比、社区广场、评估报告。
- **社区功能**：发布到社区、点赞、评论、复制分享链接、复制文案、生成 PNG 分享海报、系统分享降级。
- **导出能力**：明细 CSV、报告 HTML、批注版 Markdown / HTML、分享海报 PNG、打印或存为 PDF。
- **示例内容**：8 条社区示例动态 + 4 份一键体验示例会议（销售复盘 / 行政例会 / 项目评审 / 客服晨会）。

## 快速开始

直接用浏览器打开 `会议废话率评估智能体.html`，或在本目录启动静态服务：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000/
```

点击「载入示例纪要」或配置区里的四个「一键体验示例会议」胶囊按钮，再点「开始评估」即可看到完整效果。`Ctrl+Enter` 也可触发评估。

## GitHub Pages

本目录已包含 `index.html`（与主页面内容相同）。仓库开启 Pages 后选择 `main` 分支根目录即可获得在线链接，在线链接可真正用于社区分享——分享链接中的 `#share=` 参数只在双方都能打开同一份页面时才能解析。

## 数据与隐私

- 规则模式完全在本机浏览器运行，纪要不上传。
- 社区动态、评论、会议档案、主题偏好保存在浏览器 `localStorage`，不会同步到服务器。
- AI 语义复核为可选项，需要在页面内自行填写 OpenAI 兼容接口信息；密钥不写入文件、不进入导出内容。

## 说明

判定结果基于启发式规则和可选 AI 复核，仅供会议效率复盘参考，不应作为个人绩效评价的唯一依据。
